# Atividades 13 e 14 - Teste de Software (2026/2)

Este repositório contém as entregas das Atividades 13 e 14 de Teste de Software, com automação de testes de interface/E2E usando **Cypress**.

## Estrutura

- `Atividade_13_SauceDemo/` - Automação UI/E2E no SauceDemo (mínimo 5 testes, RF-01 a RF-08).
- `Atividade_14_AutomationTestStore/` - Automação de interface no Automation Test Store (16 testes, RF-01 a RF-16, com relatório e registro de defeitos).

## Execução

Em cada pasta da atividade:

```bash
npm install
npx cypress install   # se necessário
npm test
```

## Observações

- As evidências de execução (screenshots) são geradas em `cypress/screenshots/` ao rodar os testes.
- O relatório de estudo explicativo foi mantido apenas localmente, conforme solicitado.
